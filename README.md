# MisDecimos

Plataforma Web PWA para la gestión y reparto de décimos de lotería entre amigos y familiares.

## Stack
- **Frontend:** React + Vite + TypeScript + Tailwind CSS (Mobile-First PWA).
- **Backend:** Supabase Cloud (`xmdghpyfrblmtjtevtru`) — PostgreSQL, RLS, Funciones RPC (`SECURITY DEFINER`), Realtime y Edge Functions.
- **PWA & Push:** Service Worker con soporte offline y Web Push nativo VAPID.

Consulte [AGENTS.md](AGENTS.md) para conocer las normas de arquitectura, flujo de trabajo Git y trabajo multi-agente.
